# تسجيلات «ألعب وأتعلم» الصوتية

الهوية الصوتية المعتمدة: **صوت نسائي حنون**، فصيح، هادئ، مخارج واضحة، سرعة تعليمية طبيعية، بلا موسيقى خلفية.

## طريقة الإضافة
1. أنتج ملفات MP3 بتسجيل بشري أو مزود توليد صوت احترافي مرخّص.
2. ارفع الملفات إلى المسارات المشار إليها في `manifest.json`.
3. اربط **النص المطابق حرفيًا** بالمسار النسبي للملف تحت `assets/audio/`.
4. لا تضع مفاتيح API داخل HTML أو GitHub Pages؛ فهو موقع عام.
5. عند عدم وجود ملف أو فشل تشغيله يعود التطبيق مؤقتًا إلى صوت الجهاز.

**تنبيه:** مسارات manifest الحالية أمثلة، ولا توجد ملفات MP3 مرفوعة بعد. استبدلها بالتسجيلات الحقيقية قبل اعتبار الصوت الاحترافي جاهزًا.

## معايير الإنتاج
- تسجيل اسم الحرف مستقلًا عن صوته بالحركة.
- تدقيق بشري للنطق والحركات ومخارج الحروف، خاصة: ث، ح، خ، ذ، ض، ظ، ع، غ، ق.
- تجنب المد الزائد والتشكيل غير الطبيعي.
- 44.1kHz أو 48kHz، مستوى صوت متوازن، صمت قصير في البداية والنهاية.
- اختبار التشغيل على Android وiOS وسماعات الهاتف.
